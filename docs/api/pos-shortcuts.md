# POS keyboard shortcuts

Barcode scanners are treated as keyboards (characters then Enter). The search field stays focused; there is no scan-mode toggle.

| Action | Binding |
|---|---|
| Focus search / barcode | `/` |
| Add scanned item | `Enter` (in search field) |
| Remove selected line | `Delete` |
| Complete sale | `F2` |
| Print receipt | `F4` |
| Start new transaction | `F9` |
| Clear cart (confirm) | `Escape` |

After a completed sale the barcode field is focused immediately.
